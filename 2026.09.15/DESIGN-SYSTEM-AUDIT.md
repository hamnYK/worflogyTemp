# 홈페이지 디자인 시스템 최종 점검

## 범위
- index.html / en.html의 상단 소개, 9개 캔버스와 미리보기, 소식, 회사 정보, 문의·기사·제품 모달, 플로팅 버튼과 섹션 엘리베이터.
- DESIGN-SYSTEM.md, 공통 토큰·컴포넌트·타이포그래피 및 디자인 시스템 예시 페이지를 대조했다.
- 독립 워크숍 도구는 문서에 명시된 별도 스타일 체계이므로 이번 홈페이지 점검에서 제외했다.

## 수정
- 캔버스 초기화·재생·다음 단계 및 제품 모달 닫기 버튼에 type="button"을 명시했다.
- 제품·기사 모달에 공통 wf-dialog 클래스를 적용했다.
- 모바일 안내와 소개 강조 문장의 글자 스타일을 typography.css로 모았다.
- 강조 굵기, 도면 그림자, 미리보기 전환 시간을 공통 토큰으로 연결했다.
- 입력창과 모달의 포커스 표시를 공통 focus-ring / focus-offset에 맞췄다.
- 기사 내 보조 문구의 미정의 글자 토큰과 직접 지정 배경을 공통 토큰으로 교체했다.
- 섹션 엘리베이터 및 예시의 모서리를 radius-card로 통일했다.
- 모바일 안내·터치 제한·상시 미리보기·소개 강조 규칙을 디자인 시스템 문서 및 패턴 예시에 반영했다.

## 검증 결과
- 한글·영문, 화면 폭 320 / 390 / 412 / 760 / 1280 / 1440px에서 문서 가로 넘침 없음.
- 한글 제목 SUITE, 영문 제목 Space Grotesk, 본문 Pretendard 확인.
- 첫 제목 28~40px, 섹션 제목 22~28px, 소개 16~18px, 모바일 안내 12px 확인.
- 표시되는 일반 조작 버튼의 높이: 모바일 44px 이상 / PC 40px 이상. 이미지 카드 자체는 문서상 별도 예외.
- 이름 없는 버튼 및 누락된 버튼 type 없음.
- 모바일 스와이프로 페이지 이동, 9개 미리보기 상시 표시·가운데 정렬·원본 비율, 이미지 터치 시 모달 미표시 확인.
- 재생·초기화, PC 제품 모달, 화면 크기 전환 동작 확인.
- 문의·기사·제품 모달 Escape 닫기 및 포커스 복귀 확인.
- 언어 반복 전환 시 문의 입력 보존 확인. 실제 문의는 전송하지 않았다.
- 키보드 포커스의 공통 색상·두께, reduced-motion 미리보기 전환 제거 확인.
- 디자인 시스템 예시 페이지 390 / 1280px 가로 넘침 없음.
- 홈페이지 실행 중 JavaScript 오류 없음.

## 검증 방법과 한계
로컬 Chrome 렌더링, 터치 에뮬레이션, DOM·계산된 스타일 검사와 화면 캡처를 사용했다. 실제 iOS Safari 및 실물 기기 검증은 하지 않았다. 기존 화면별 CSS의 모든 숫자와 중복 선언을 제거하는 전면 리팩터링은 수행하지 않았다. 검사 중 화면 밖 캔버스의 내부 크기가 영역보다 큰 경우가 있었으나 부모 영역에서 잘려 문서 가로 넘침을 만들지 않았고, 사용자 화면의 스크롤·미리보기 회귀 검사는 통과했다.
