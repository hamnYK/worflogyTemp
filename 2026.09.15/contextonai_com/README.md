# contexton design system

브라우저에서 index.html을 열면 디자인 시스템을 확인할 수 있습니다. 별도 설치나 빌드는 필요하지 않습니다.

- index.html: 개요, 색상, 타이포그래피, 컴포넌트, 관계, 디자인 원칙
- styles.css: 공통 CSS 토큰, 반응형 레이아웃, 컴포넌트 상태
- app.js: 색상 복사, 토큰 JSON 다운로드, 노드 상태 전환, 200자 의견 시연, 관계 선택

현재는 디자인 검토용입니다. 입력은 페이지 안에서만 유지되며 새로고침하면 초기화됩니다. 로그인, 이미지 업로드, 실제 드래그앤드롭, 데이터베이스, 실시간 협업은 아직 구현하지 않았습니다. 참여자 및 노드의 이미지는 예시입니다. 예시 이미지는 외부 요청 없는 CSS 그래픽입니다.

한국어 본문은 운영체제의 한글 고딕을 사용하고, 영문 표지 제목은 Georgia를 사용합니다. 외부 폰트와 라이브러리가 필요하지 않습니다.

검증: JavaScript 문법, HTML id 및 앵커 연결, 의견의 빈 값 처리와 노드 반영, 노드 상태 3종과 관계 유형 6종을 확인했습니다. 브라우저 자동화 환경의 경로 오류로 렌더링 시각 검증은 완료하지 못했습니다.

브랜드의 표기는 소문자 contexton으로 통일합니다.


## 링크와 관계 해석

링크 AB는 여러 관계 해석을 포함합니다. 각 해석에는 관계 계열, 이름, 정의, 제안자가 있고, 사용자 의견은 해당 해석에 속합니다. 관계 유형으로서의 지지와 해석에 대한 의견의 지지는 별개입니다.

relationships.js에서 관계 해석 제안, 해석별 200자 의견 추가, 지지함/지지하지 않음/판단 유보 집계를 시연합니다. 집계는 의견 건수이며 고유 사용자 수나 진실 판정이 아닙니다. 의견이 없는 상태는 지지하지 않음과 구별합니다. 지지를 받지 못한 해석도 삭제하지 않습니다. 현재는 작성자가 입장을 명시하는 디자인이며 자동 의미 분석이나 평판 점수는 적용하지 않았습니다.

검증: 해석별 집계 분리, 지지 및 비지지 반영, 빈 의견과 잘못된 입장 거부, 200자 경계, JavaScript 문법, HTML 앵커 및 ID를 확인했습니다. 브라우저 시각 검증은 미완료입니다.

## 네트워크를 근거로 글쓰기

Writing 섹션은 링크 AB의 여러 해석과 의견을 문학·비문학의 글로 구성하는 디자인 시연입니다. writing.css는 글쓰기 작업 영역과 근거 표시, writing.js는 재료 선택·예시 초안 구성·문단 근거 확인·텍스트 다운로드를 담당합니다.

- 노드 A·B와 링크 AB가 범위인 하위 네트워크 예시이며, 관계 해석을 복수 선택할 수 있습니다.
- 문학/비문학과 의견 관점(상반된 의견, 지지 의견, 지지하지 않는 의견)을 선택한 뒤 예시 초안을 구성합니다.
- 실제 AI 모델을 호출하지 않습니다. 준비된 서술과 선택한 네트워크의 정의·의견을 조합합니다.
- 문단별 출처를 따라 노드, 관계 정의, 작성자와 의견을 확인할 수 있습니다. 준비된 창작 장면과 추가 확인이 필요한 서술은 별도 표시합니다.
- 초안은 구성 시점의 데이터를 복사해 보관합니다. 원본 관계를 수정해도 기존 초안 근거는 바뀌지 않고 재구성 안내가 표시됩니다.
- 초안과 근거를 함께 TXT로 다운로드할 수 있습니다. 새로고침 후에는 데이터가 유지되지 않습니다.

검증: 문학/비문학과 세 관점 조합 6종, 선택한 관계 범위, 의견 필터, 출처 구분, 원본 변경 후 스냅샷 보존, 의견 없음 상태, 근거를 포함한 다운로드 내용, HTML 참조와 JavaScript 문법을 확인했습니다. 실제 브라우저 렌더링은 확인하지 못했습니다.
