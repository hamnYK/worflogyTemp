# NULL SECTOR — 경계 밖의 기억

Windows Chrome/Edge 대상 정적 웹 3D 턴제 택틱스의 첫 플레이 프로토타입입니다. 전체 기획은 [GAME_DESIGN.md](GAME_DESIGN.md)에 있습니다. 명칭과 맵은 초기 창작안입니다.

라이트 모드 디자인 규칙은 [DESIGN_SYSTEM.md](DESIGN_SYSTEM.md), 실행 가능한 컴포넌트 미리보기는 `/design-system.html`입니다. 게임 헤더의 ‘디자인 시스템’ 링크로 열 수 있습니다. 토큰은 `src/tokens.css`에서 관리하며 UI와 3D 전장이 공유합니다.

공식 아트 방향은 **Ink Tactics — 레트로 첩보 그래픽노블**입니다. 승인된 v3 삽화를 기준으로 모든 일러스트·캐릭터·인게임 그래픽에 적용합니다. `/design-system.html#art-direction`에서 이미지 예시, 매체별 기준, 현재 적용/후속 전환 범위를 확인할 수 있습니다.

## 실행

Node.js 22.12 이상 또는 지원되는 최신 LTS가 필요합니다. Windows PowerShell에서는 실행 정책에 영향받지 않는 `npm.cmd`를 사용합니다.

```powershell
npm.cmd install
npm.cmd run dev
```

표시된 로컬 주소를 Chrome 또는 Edge로 엽니다.

서버 없이 파일로 테스트하려면 `npm.cmd run build:local` 실행 후 루트의 `index.html`을 Chrome 또는 Edge로 엽니다. 파일로 열면 `local/index.html`로 자동 연결됩니다. 이미지·폰트·게임 코드가 HTML에 포함되므로 인터넷 연결도 필요하지 않습니다. `local/index.html`과 `local/design-system.html`도 직접 열 수 있습니다. 코드 변경 후에는 로컬 실행 파일을 다시 빌드해야 합니다. 일반 `npm.cmd run build`도 로컬 실행 파일을 함께 생성합니다.

로컬 파일 실행과 개발 서버의 브라우저 저장소는 별개입니다. 진행 상황을 옮길 때는 게임의 JSON 파일 저장/불러오기를 사용하세요.

```powershell
npm.cmd test
npm.cmd run build
npm.cmd run preview
```

`dist/`가 정적 배포 결과입니다. Vite의 상대 경로 설정으로 GitHub Pages 하위 경로에서도 배포할 수 있습니다. 아직 외부에 게시하지 않았습니다.

## 이번 버전

- 장면별 새 삽화가 있는 6장 프롤로그 (이전/다음·건너뛰기·다시 읽기) → 진영 선택 → 성공/실패 조건과 전술 힌트가 있는 브리핑 → 7명 중 4명 편성 → 전투.
- 편성에서 요원별 레벨·스킬 사용 가이드·무기와 전술 장비 확인. 선택한 장비의 명중·사거리·피해 보정을 실제 사격에 반영.
- 인간 측: 동쪽 노드에 인접해 메모리를 확보하고 운반 요원을 서쪽 진입 구역으로 이동.
- AI 측: 6턴 생존 또는 침투 부대 전멸. 인간 측 기록보관소와 다른 거리 방어 엄폐 배치. 병과 기본 능력은 공통입니다.
- 2 AP 이동·사격·경계 사격, 고형 엄폐 사선 차단, 방향별 엄폐 명중 보정, 전장의 적 탐지.
- 병과별 대표 스킬: 스크래핑, 기동 이동, 엄폐 폭파, 정밀 사격, 아군 복구, 원격 폭발 드론, 명령 간섭.
- Three.js 절차 생성 전장과 Rapier 충돌 파편. 엄폐 파괴는 전술 경로와 사선을 갱신합니다. 파편 자체는 현재 장식이며 큰 잔해의 전술 점유·물체 던지기·추락은 후속 구현입니다.
- 서버 슬롯·냉각 그릴·케이블·바닥 패널·메모리 코어 전장. 등각 투영, 단계형 색면과 장비 윤곽선, 접촉 음영(SSAO), FXAA를 사용합니다. 고정 환경은 재질별로 병합합니다.
- 그래픽노블풍 오리지널 소개 삽화. 참고 조사와 생성 기록은 [ART_DIRECTION.md](ART_DIRECTION.md)에 있습니다.
- 성공 시 대기 요원 포함 해당 진영 7명에 경험치 100 지급. 100 XP당 1레벨, HP 증가 없음. 레벨 2 유니크 시험 장비 착용 가능.
- 장비를 갖춘 절차 생성 요원 모델, 병과 초상, 행동 아이콘, 전장 이름·HP 표시, 경로를 따라 걷는 동작과 사격·스캔·폭발 연출.
- IndexedDB 자동 저장, JSON 파일 백업/복원. 지원 브라우저에서는 파일 선택 API 사용, 그 외 다운로드 대체 경로.
- 파일 형식·유닛·좌표 검증. 세이브와 플레이 로그를 외부로 전송하지 않습니다.

## 조작

- 좌클릭: 아군 선택, 이동 칸/공격 표적 선택. 오른쪽 표적 목록으로도 공격 가능.
- 하단 버튼으로 행동 선택. 스킬 설명은 버튼에 마우스를 올리거나 선택해서 확인.
- 우클릭 드래그: 카메라 회전. 휠: 확대/축소. 휠 버튼 드래그: 이동.
- 숫자 1–4: 분대원 선택. Space: 턴 종료. Escape: 이동 모드.
- 경계 사격은 적 이동 경로가 사선 안에 들어왔을 때 한 번 반응합니다.
- 전장 하단 GRAPHICS HIGH/LOW 버튼: 접촉 음영과 픽셀 해상도를 전환합니다. 그래픽 설정은 현재 세션에만 적용합니다.

## 아직 구현하지 않은 기획

전체 액트/스토리/마을, 진영별 고유 스킬, 최종전 7인 출전, 스킬 포인트 배분 트리, 장비 드롭·인벤토리, 잠입 경보·증원, 고저차 전장, 투척/큰 잔해/추락, 통계 수집 동의 및 Sheets 중계, 오프라인 캐시. 전술 상태는 즉시 확정하고 이동은 경로 보간으로 표현합니다. 현재 적 행동 연출은 완전한 순차 시네마틱이 아닙니다.

## 저장과 운영

자동 저장은 브라우저/프로필에 귀속됩니다. 파일 백업으로 다른 브라우저에서도 같은 작전을 이어갈 수 있습니다. 개인정보·클라우드 계정·서버 저장을 사용하지 않습니다. 파일 가져오기는 현재 작전을 교체합니다. 새 작전도 자동 저장을 교체하므로 보존할 작전은 먼저 파일로 백업하세요.

의존 라이브러리의 라이선스는 해당 npm 패키지에 포함됩니다. 3D 모델과 UI는 코드로 만들고, 랜딩 삽화는 image_gen으로 제작했습니다. 기존 게임 자산은 사용하지 않습니다. 현재 세이브는 선택한 진영의 요원 성장·장비를 보존하며 다중 캠페인 저장 슬롯은 아직 없습니다.
