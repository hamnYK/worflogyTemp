# 로컬 세이브 v2

세이브는 콘텐츠 원본이 아니라 미션 ID와 진행 상태를 기록한다. 암호화나 신뢰 가능한 치팅 방지 수단은 아니다.

## 저장 항목

- format/version/contentVersion: 파일 형식과 콘텐츠 호환 버전
- mission, mapVersion, encounterVersion: 게임 내부 미션·맵 정의 참조
- roster, agents: 편성 ID와 각 요원의 경험치·장비 ID
- progress: 턴, 난수 상태, 탐지 기한, 선택 요원, 메모리 운반자, 임무 상태, 최근 30개 작전 기록 등
- units: 고정 유닛 ID와 초기 상태에서 달라진 좌표·HP·AP·소모품·경계·쿨다운·복구 상태 등
- cover: 피해를 받은 엄폐물 ID와 현재 HP만 기록
- defense: 중계소 ID와 침투/복구 진행값. null은 기존 목표 없는 임무의 호환 상태

이름, 병과 정의, 최대 HP, 엄폐물 좌표·높이·기본 내구도, 중계소 이름·좌표, 메모리 목표 좌표, 일러스트·모델·스크립트는 파일에 복제하지 않는다. 작전 로그에는 플레이 중 표시된 이름과 문장이 포함될 수 있다. 이동한 미탐지 적의 좌표 등 복원에 필요한 변경값은 여전히 남는다.

## 복원 및 검증

게임에 내장된 해당 버전의 미션으로 초기 상태를 만든 뒤 허용된 변경값을 적용한다. ID·버전·편성·수치 범위·장비 조건·좌표 중복·복구 상태 등을 검증한다. 정의 필드 주입, 알 수 없는 항목, 중복 엄폐물 ID는 거부한다. 미지원 버전은 추측해서 복원하지 않는다.

기존 v1 JSON과 IndexedDB/탭 기록은 계속 불러올 수 있다. 다음 저장부터 v2를 사용한다. 기존 사용자 파일을 자동으로 수정하지 않는다.

콘텐츠 변경 시 기존 버전의 정의를 유지하거나 명시적인 마이그레이션이 필요하다. 클라이언트 게임 데이터 자체의 추출, 유효 범위 안의 세이브 변조를 차단하는 설계는 아니다.

구현: `src/save-codec.js`, `src/rules.js`. 모든 로컬 저장 경로는 공통 packSave/validateSave를 사용한다.
