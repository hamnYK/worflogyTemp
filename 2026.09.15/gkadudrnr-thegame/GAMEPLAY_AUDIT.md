# 게임플레이 정합성 점검 — 2026-09-25

현재 프로토타입의 규칙, 실제 UI 입력, 편성 안내, 저장 상태를 대조했다. 발견한 재현 가능한 오류는 수정했다. 이것은 전수 무결성 보증이나 사람 대상 밸런스 검증은 아니다.

## 확인하고 수정한 오류

| 항목 | 이전 동작 | 수정 |
|---|---|---|
| 회수 임무 경계 사격 | 이동 경로 중 피격됐지만 적 좌표는 경로 끝으로 이동. 쓰러진 적이 목적지 칸을 점유 | 방어·회수 모두 칸별 이동과 경계 판정을 공유. 쓰러진 위치에서 경로 중단 |
| 병과 스킬 검증 | 내부 스킬명으로 `act`를 직접 호출하면 병과 선택과 쿨다운 경로를 우회 가능. 일반 UI는 이 경로를 노출하지 않았음 | 허용된 커맨드만 접수. 병과 능력은 `skill`을 통해서만 해석·검증 |
| 완전 탄약 고갈 적 | 방어 엄호조가 충전·예비 모두 없어도 사격을 반복 선택 | 사격/교체 자원이 없으면 목표 접근을 선택 |
| 빈 배터리 경계 표시 | 경계 설정 후 남은 1발을 일반 사격에 쓰면 발사 불가능한 ‘경계 중’ 상태가 남음 | 마지막 충전을 사용하면 경계 해제 |
| 저장 불러오기 유닛 잔상 | 같은 진영 12유닛 작전에서 8유닛 과거 저장을 불러오면 이전 추가 적 모델·라벨이 남을 수 있음 | 현재 상태에 없는 모델·라벨·이동·자세 기록 제거. 브라우저에서 12→8→12 검증 |

재현 테스트는 앞의 네 규칙 오류에 대해 수정 전 실패와 수정 후 통과를 확인했다. 유닛 잔상은 모델 관리 코드 확인과 수정 후 브라우저 검증으로 확인했다.

## 추가 방어 처리

- 적 사격 효과는 발사 순간의 시야 여부를 함께 전달하고, 보이지 않았던 적의 레이저 원점은 렌더링하지 않는다. 현재 적 사거리(7)가 아군 시야(8) 안에 있으므로 정상적인 현재 규칙에서 미탐지 사격 재현을 주장하지 않는다. 향후 사거리·시야 변경 시 정보 누출을 막는 처리다.
- 전장 셀 클릭은 숨은 적을 공격 대상으로 자동 선택하지 않는다. 미탐지 적을 우연히 클릭했을 때 표적 정보창으로 존재가 드러나는 경로를 줄였다. 이동 가능 경로 계산은 실제 점유 칸을 따르므로 완전한 이동 경로 기반 정보 은닉까지 구현한 것은 아니다.

## 서로 충돌하지 않는 것으로 확인한 규칙

- 아군 턴 시작 2 AP, 커맨드마다 1 AP. 사격 두 번 가능. 경계 설정 1 AP, 자동 반응 사격은 추가 AP 없이 충전 1회분 사용.
- 일반/저격/경계는 빗나가도 충전 소모. 미리보기·취소는 AP·충전·난수 변경 없음. 빈 총의 잘못된 공격은 자원 변경 없음.
- 배터리 교체는 기존 충전을 버리고 예비 1개·1 AP 사용. 스킬 대기는 유지. 응급 키트는 자신/인접한 살아 있는 아군만 HP 3 복구하며 전투 불능 복구 불가.
- 기술병은 전투 불능 아군을 HP 5로 복구하고 해당 요원은 다음 아군 턴부터 행동. 발생 턴을 제외한 이후 아군 턴 세 번의 복구 기회 뒤 소멸.
- 저격은 저격총·분대 직접 시야·사선 필요. 장착 시 이동 2칸. 치명타 확률 25%는 **명중했을 때의 조건부 확률**이며, 치명타로 HP 0일 때만 즉시 소멸.
- 방어 중계소는 라운드당 침투 +1 상한, 아군 턴당 노드 복구 1회. 침투 3단계 실패가 마지막 라운드 생존 성공보다 우선.
- 현재 소모품은 저장/복원해도 소모 상태 유지. 이전 소모품 스키마가 없는 저장은 명시적인 초기 보급 마이그레이션. 이전 생존형 방어 저장에 새 중계소 목표를 소급 적용하지 않음.
- 두 진영 12개 자동 행동 시퀀스에서 실패 행동의 무변경과 성공/턴 종료 후 저장 왕복 일치 검사.

## 남아 있는 설계·구현 범위

1. **소멸은 해당 가상 전장에서의 제거로 확정했다.** 캠페인 영구 상실을 뜻하지 않으며, 다음 작전에서 다시 편성할 수 있는 것이 정상 설정이다. 이 항목은 결함이나 미구현 과제가 아니다.
2. **시야는 거리+장애물 기준이다.** 방향별 시야각·마지막 목격 위치·완전한 잠행 상태는 아직 없다. 엄폐가 곧 은신을 뜻하지 않는다.
3. **적은 아군과 동일한 병과 운용을 하지 않는다.** 방어 적은 2 AP 목표 지향 행동, 회수 적은 기존 단순 이동/사격 AI다. 적의 고유 병과 스킬·치유·저격 장비 운용은 없다. 적 모델의 병과와 실제 보유 능력을 혼동하지 않도록 관찰한 능력만 공개한다.
4. **기존 승률 수치를 현재 밸런스 근거로 사용하면 안 된다.** 이전 800회/400회 실험 뒤 저격·배터리 규칙이 바뀌었다. 이번 검증은 규칙 정합성 검사이며 제한 턴·예비 배터리 수·치명타 확률의 최종 적정성을 증명하지 않는다.
5. 스킬 포인트 배분 트리, 실제 세트 아이템, 최종 보스 7명 동시 출전은 미구현이다. 현재 4인 시험 작전의 코드로 전체 액트 완성을 주장하지 않는다.
6. 적 턴 효과는 일부 동시 재생된다. 계산은 순차적이지만 행동마다 카메라·레이저·이동을 순서대로 보여주는 연출은 후속 개선 대상이다.
