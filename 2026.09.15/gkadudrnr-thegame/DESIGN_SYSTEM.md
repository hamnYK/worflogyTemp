## 전장 일러스트 스타일 보강 (2026-09-25)

### 적 정보 카드의 그래픽 표현

- 아군과 적군 카드는 모두 90px 높이로 통일한다. 탐지 단계와 확인 능력은 초상 아래 작은 아이콘으로 표시하고 툴팁·접근성 이름을 제공한다. 별도 상단·하단 텍스트 행은 사용하지 않는다.

- 탐지 단계는 병과와 무장이 드러나지 않는 공통 SVG 실루엣과 비수치 점선 막대만 사용한다. 숨겨진 HP·역할을 이미지나 막대 폭으로 노출하지 않는다.
- 직접 목격한 주요 요원은 상대 진영의 승인 초상, 일반 전투병은 공통 전투병 그래픽으로 표시한다. HP 막대와 상태 아이콘을 병행한다.
- 목격/교전 관찰을 상단의 눈 심볼과 단계 문구로 표시한다. 실제 관찰한 레이저 사격만 하단 조준 심볼로 공개하고 미확인 능력은 잠금 표시를 사용한다.

### 머리 위 상태 아이콘

- 캐릭터 위에는 HP 숫자·백분율·이름·상태 문구를 표시하지 않는다. SVG 상태 아이콘 하나를 표시하며 상세 수치는 좌우 유닛 패널에서 확인한다.
- 정상=방패, 부상=붕대, 치명상=경고, 전투 불능/복구 대기=십자. 색뿐 아니라 모양으로 구분한다. 접근성 이름은 유지한다.
- 스캔 신호는 신호 아이콘만 표시하며 실제 적 HP나 상태를 노출하지 않는다. 중계소 등 임무 목표 표시는 별도로 유지한다.

### 정면·좌우 판정 수정

- 경계 선택은 좌·정면·우·후면 4방향이다. 후면은 선택 전 정면의 반대쪽 90°이며, 확정 1 AP·자동 사격 1회 0 AP 규칙을 동일하게 적용한다. 확정 후 해당 방향이 새 정면이 된다.

- 좌·정면·우는 요원 정면을 기준으로 한다. 화면 좌우나 카메라 회전 기준이 아니다.
- 엄폐의 웅크림·기울임은 유지하되 엄폐물에 따라 모델 전체가 판정과 다른 방향으로 돌아가는 동작은 제거했다. 이전의 '엄폐 모델 방향과 전술 방향은 독립' 규칙을 대체한다.
- 경계 확정 방향은 새 정면이 되며 경계 종료 후에도 유지한다. 이동과 사격은 새 방향을 갱신한다. 경계 중 일반 사격의 순간 조준과 별개로 준비한 경계 영역은 유지한다.
- UI 갱신 시 모델 방향 초기화를 제거했다. 적 사격과 아군 경계 반응 사격도 방향을 갱신한다.

### 전장 전체의 공통 화풍

- 기준 이미지는 `03-shutdown-v3.png`, `05-memory-v3.png`와 승인된 요원 초상이다. 적용 범위는 아군·적군·서버·엄폐물·바닥·건축 배경 전체이다.
- 화면 전체의 3D 렌더에 절제된 잉크 윤곽을 적용한다. HUD에는 후처리를 적용하지 않는다. 낮은 그래픽 설정에서도 같은 화풍을 유지한다.
- 인간 임무의 배경은 기둥과 보, 연속된 기록보관 랙으로 구성하고 AI 임무는 수평 창 띠, 돌출 창턱, 출입구와 가로 시설로 도시 공간을 표현한다. 아이보리 건축 면과 청회색 음영을 양쪽에 동등하게 사용한다.
- 외곽 보행 공간과 시설은 전투 격자 밖에 놓는다. 건축 부품은 재질별로 병합해 렌더링 호출을 줄인다. 추가 구현은 `src/world-illustration.js`에 정의한다.

- 3D 요원은 초상의 후드, 코트 자락, 라펠, 장갑판, 하네스와 병과 장비를 형태로 반영한다. 기술병·드론 요원은 얼굴과 머리카락으로도 구분한다.
- 사각 블록을 단순히 쌓는 표현을 줄이고 끝이 좁아지는 의복과 다각형 옷 주름을 사용한다. 인간은 청회색, AI는 회보라색이며 동일한 명암 기준을 적용한다.
- 3단계 셀 명암과 잉크 윤곽을 보강하고 조명의 과도한 밝기를 낮춘다. 서버 외장과 바닥에는 제한된 패널 선·마모 표현을 쓴다. 미세한 해칭으로 전술 가독성을 떨어뜨리지 않는다.
- 환경의 추가 배관·벽 선·표식은 전장 밖 장식이다. 이동·엄폐·시야 판정은 기존 격자 규칙을 유지한다.
- 구현: `src/ink-geometry.js`, `src/art.js`, `src/scene.js`. 전용 수작업 캐릭터 모델과 텍스처 수준까지 완성된 것은 아니며, 초상과 세부 디자인 일치는 후속 제작 대상이다.
- Chrome·Edge에서 양 진영, 확대, 경계 명령, 그래픽 품질 전환을 확인했다.

## 최신 UI 마감 규칙 — 단일 강조 (2026-09-25)

`src/tactical-finish.css`는 게임과 갤러리가 공유하는 최종 표현 규칙이다. 아래 이전 기록 중 중첩 외곽선·그라데이션 표현보다 이 규칙을 우선한다.

- 편성 카드의 상세 선택은 왼쪽 표시선 하나, 투입은 채운 배경과 체크·문구로 구분한다. 카드 외곽 outline, 내부 버튼 그림자, 초상 테두리를 동시에 쓰지 않는다.
- 키보드 포커스는 `:has(button:focus-visible)`에서 카드 내부 2px 단일 선으로 선택 표시선을 대체한다. 투입 버튼의 포커스는 문구 밑줄로도 구분한다. 키보드 포커스를 없애지 않는다.
- 요원 상세는 큰 캐릭터 그림과 정보 위계로 구분하며 중첩 프레임을 사용하지 않는다. 브리핑은 작전 배경 삽화와 얇은 구획선, 편성은 캐릭터와 출전 상태를 중심으로 한다.
- 전투 패널은 준비 화면과 연결되는 밝은 종이색·청회색을 사용한다. 선택 행동은 하단 선 하나, 적은 위험 색 표시선, 초상은 무테두리. 반복된 파란 상자·그라데이션·그림자를 줄인다.
- 실제 3D 전장 모델·애니메이션의 품질은 UI 마감과 별도 개선 과제이며, 이번 마감으로 상용 게임 수준의 전장 아트가 완성됐다고 표현하지 않는다.

## 방향과 기준

**공식 아트 방향: 레트로 첩보 그래픽노블 / Ink Tactics.** 사용자 승인한 프롤로그 v3를 게임 전체의 기준으로 삼는다. 모든 신규·개선 일러스트, 캐릭터 초상과 전신, 장비, 3D 전장, 애니메이션, 효과, UI에 적용한다. 장면별 임의의 화풍 혼용을 허용하지 않는다. 기존 Data Light의 라이트 UI와 정보 색 체계는 이 아트 방향 안에서 유지한다.

### 전체 그래픽 공통 규칙

- 윤곽: 굵고 각진 짙은 잉크 선. 외곽은 강하게, 내부 설명선은 적게 사용한다. 작은 화면에서도 실루엣이 먼저 읽혀야 한다.
- 명암: 기본색과 그림자 중심의 2–3단계 명암. 넓고 단단한 그림자 면으로 형태를 만든다. 질감과 미세 묘사로 입체감을 채우지 않는다.
- 색: 밝은 아이보리·청회색·슬레이트 블루를 바탕으로 제한된 보라·청록·앰버를 쓴다. 진영 고유색은 소속을 구분할 뿐 선악을 뜻하지 않는다. UI의 적·아군 의미 색과 캐릭터 고유색은 구분한다.
- 재질: 옷, 금속, 콘크리트 모두 같은 색면 언어로 단순화한다. 실사 PBR 광택, 과도한 반사·블룸·노이즈·해칭·종이 질감을 기본 표현으로 사용하지 않는다.
- 구도: 대각선과 전경·중경·배경의 명확한 층. 얼굴·손·무기·목표물에 시각적 우선순위를 둔다. 정보 없는 장식이나 조밀한 배경으로 주요 행동을 가리지 않는다.
- 정서: 인간과 AI 모두 판단하고 준비하고 행동하는 존재로 표현한다. 영웅의 후광, 악당의 역광, 무력한 희생자 구도로 특정 진영 선택을 유도하지 않는다.
- 금지: 실사풍·치비·장난감 같은 둥근 형태로 이탈, 장식용 이모지와 반복 화살표, 전면 네온 녹색, 무분별한 글리치.

Shadow Watch는 형태와 색면·연출의 참고 대상이며 원작의 캐릭터·로고·UI·이미지를 복제하거나 배포 자산으로 포함하지 않는다.

AI 데이터센터의 백색 조명과 냉각된 공간을 차가운 백색·아이스 블루로 표현한다. 주요 행동과 아군은 코발트, 네트워크 정보는 청색, 기억과 목표 노드는 보라색, 적과 위험은 코랄색으로 구분한다. 녹색은 정상 연결·완료에만 사용한다. UI와 3D 전장이 같은 의미 체계를 공유하며 라이트 모드를 고정한다.

- 실행 미리보기: `/design-system.html`. 게임 헤더의 ‘디자인 시스템’ 링크로 접근.
- 단일 토큰 원본: `src/tokens.css`. 색상·타입·간격·곡률·그림자·모션을 정의.
- 기본 컴포넌트: `src/style.css`. 실제 화면의 변형은 `src/preparation.css`, `src/prologue.css`, `src/game-hud.css`가 관리한다.
- 가독성: `src/readability.css`. 준비 화면과 전투의 작은 정보 글자를 보정하며 갤러리에도 동일 적용한다.
- 전장 색상: `src/theme.js`로 CSS의 `--scene-*` 토큰을 읽는다. 변경은 새로고침 시 반영.
- 미리보기 전용 배치: `src/design-system.css`. 게임 컴포넌트 상태는 공통 CSS를 사용.

## 글자·간격·형태

- 한글 제목: Do Hyeon(도현체) 400. 인공 굵기를 만들지 않고 제목·대표 문구·작전 결과에 사용.
- UI 본문: Noto Sans KR Variable. 설명·로그·한글 버튼은 읽기 쉬운 본문 서체를 사용.
- 로고·코드네임·좌표·AP·숫자: Oxanium Variable. 각진 SF HUD 서체와 tabular-nums를 적용. 고정폭 기술 코드 표기용 Consolas 토큰은 별도로 유지.
- `src/fonts.css`에서 Fontsource 패키지를 불러와 Vite 정적 배포에 포함한다. 런타임 외부 폰트 서버 요청 없음. WOFF2 unicode-range로 필요한 문자 조각을 로드하고 font-display: swap으로 대체 글자를 먼저 표시한다.
- 세 서체의 SIL OFL 1.1 원문을 `public/licenses/`에 포함하며 빌드 결과에도 복사된다. 출처: [Do Hyeon](https://github.com/google/fonts/tree/main/ofl/dohyeon), [Oxanium](https://github.com/sevmeyer/oxanium), [Noto Sans KR](https://github.com/google/fonts/tree/main/ofl/notosanskr).
- 글자: 의미 있는 보조 정보 최소 12px, 버튼·조밀한 UI 13px, 작전 본문 14px, 긴 프롤로그 15px / 줄간격 1.95. 18px 소제목, 24px 섹션 제목, 30–46px 화면 제목. 전투 HP·AP·행동 비용과 편성 병과·스킬은 12px 이상. 의미가 중복된 순번이나 개발용 토큰 코드는 더 작을 수 있지만 핵심 정보를 대체하지 않는다.
- 간격: 4 / 8 / 12 / 16 / 24 / 32 / 48 / 64px. 카드 안 12–16px, 패널 안 16–24px, 큰 영역 사이 32–64px.
- 모서리: 준비 화면 0px (`--radius-paper`), 전투 카드·행동 2px (`--radius-hud`), 공통 보조 버튼·배지 4px. 초기 기본 컴포넌트용 8px·16px 토큰은 남아 있으나 신규 편성·전투 패널의 기본값으로 쓰지 않는다.
- 그림자는 떠 있는 알림·결과와 주요 편성 패널에 제한. 기본 구분은 밝은 표면과 선으로 처리.

## 컴포넌트와 상태

- 주요 버튼: 준비 화면 청회색 `--paper-action` / 흰 글자, 전투 코발트 / 흰 글자. 화면의 진행·확정 행동에 사용.
- 보조 버튼: 흰 바탕/회색 테두리. 저장·불러오기 등에 사용.
- 선택 카드: 아이스 블루 바탕, 코발트 테두리와 왼쪽 표시. 선택된 행동은 하단 표시도 사용.
- 비활성: `disabled` 속성, 회색 바탕·글자, 차단 커서. 불가 상태를 문구로 표시.
- 키보드: `:focus-visible` 3px 파란 외곽선 + 3px 간격. 호버와 구분.
- 목표: 번호 또는 완료 체크 + 제목 + 세부 조건.
- HP: 막대와 현재/최대 수치. AP: 채운/빈 기호와 행동 비용.
- 알림: 밝은 카드, 왼쪽 강조선, 명확한 문장. 상태 메시지는 `role=status` 사용.
- 전투 화면: 좌측 목표·분대, 중앙 전장, 우측 표적·로그, 하단 행동.
- 모션: 기본 전환 140ms, 진영 카드 160ms·호버 상승 4px. `prefers-reduced-motion`에서는 UI 애니메이션·전환·호버 이동 제거. 3D 게임 시뮬레이션은 별도다.

## 적용 범위

편성·진영 선택, 전투 HUD, 행동/표적/분대 카드, 저장 버튼, 알림, 결과, 로딩, 3D 전장을 라이트 팔레트로 변경했다. 전투 규칙과 세이브 형식은 바꾸지 않는다. 현재 데스크톱 최소 검증 화면은 1280×720이며 패널 내용은 세로 스크롤을 허용한다.

후속 화면(마을, 스킬 트리, 장비, 스테이지 선택)은 먼저 이 토큰과 상태 규칙을 재사용한다. 새 스타일은 역할에 맞는 토큰으로 추가하고 화면마다 별도 색상 체계를 만들지 않는다.

## 전술 게임 HUD 확장

### 이모지 금지

게임 화면과 디자인 시스템에서 유니코드 이모지와 컬러 이모지를 사용하지 않는다. 의미가 필요한 아이콘은 `src/symbols.js`의 단색 SVG 또는 CSS 심볼을 사용하며 기존 전술 SVG 아이콘과 선 굵기·색을 맞춘다. 아이콘만 있는 버튼에는 접근 가능한 이름을 제공하고 장식 SVG는 보조 기술에서 제외한다. SVG를 넣을 수 없는 네이티브 선택 옵션은 `(잠김)`처럼 상태를 텍스트로 명시한다. 단순 장식을 위해 아이콘을 추가하지 않는다.

### 장식용 화살표 제한

진영 카드, 이동·실행 버튼, 저장·이어하기 링크에 화살표 문자를 관습적으로 붙이지 않는다. 클릭 가능 여부는 구체적인 행동 문구와 호버·포커스·선택 상태로 표현한다. 화살표는 이동 방향, 공격자와 표적의 관계, 절차의 순서처럼 의미가 필요한 경우에만 사용한다.

### Prototype 01: 그래픽노블 방향 (2026-09-25)

Shadow Watch 선호에 맞춰 준비 화면을 밝은 종이색과 청회색 잉크로 확장했다. `src/preparation.css`가 랜딩·작전 서류·요원 상세의 전용 스타일을 관리한다. 전투의 코발트 아군·코랄 적 의미 색은 유지한다. 등각 카메라, 단계형 음영, 큰 장비 윤곽선을 적용했다. 현재 승인 삽화는 v3이며 참고 자료와 프롬프트는 [ART_DIRECTION.md](ART_DIRECTION.md)에 기록한다. 디자인 시스템 갤러리에서 최신 아트 기준과 공통 컴포넌트를 확인한다.

`src/game-hud.css`는 공통 색상·타입 토큰 위에 게임 화면 전용 배치를 더한다. 패널·행동 버튼 모서리를 2px로 줄이고 분대 초상, 병과 아이콘, 분절 HP, 전장 이름/HP 표식을 사용한다. 디자인 시스템 페이지의 실제 화면 컴포넌트 영역은 준비 화면 CSS와 `.ds-game-preview`로 범위를 지정한 원본 전투 HUD CSS를 재사용한다. 갤러리 전용 배치만 별도로 정의하며 게임 상태나 저장 데이터를 변경하지 않는다. 3D 아트는 `src/art.js`, 렌더링과 효과는 `src/scene.js`, 초상·아이콘은 `src/ui-art.js`에서 관리한다.

## 가독성과 접근성 검수

- 글자가 작다는 사용자 피드백에 따라 10–11px이던 핵심 보조 정보를 12–14px로 확장했다. 긴 프롤로그는 15px. 글씨가 커진 만큼 세로 공간을 허용한다.
- 일반 활성 텍스트의 대비 목표 4.5:1. 이는 제작 기준이며 모든 자산에 대한 접근성 인증을 의미하지 않는다.
- 키보드 포커스는 3px 외곽선으로 표시한다. 진영 카드는 5px, 공통 버튼과 select는 3px 간격. 아이콘 전용 버튼에는 접근 가능한 이름을 제공한다.
- 주요 버튼 최소 높이 40px, 장비 select 42px. 편성 보조 토글은 최소 36px 높이·48px 폭. 전투 행동 버튼 높이 80px.
- 1280×720에서 본문·행동 비용·HP/AP 잘림, 가로 넘침, 저작권/행동 바 겹침을 확인한다. Chrome와 Edge에서 양 진영 진입을 확인한다.

## 전장 소멸·방향 경계 확정 (2026-09-25)
- 소멸은 해당 가상 전장에서의 제거다. 캠페인 영구 상실을 요구하지 않는다. 이전 점검에서 이를 설계 미정 항목으로 둔 해석은 정정한다.
- 경계 버튼 후 좌/정면/우를 선택해 명령을 완료한다. 방향 확정 시에만 1 AP 소모. ESC·바깥 클릭·취소는 상태와 자원을 변경하지 않는다.
- 방향은 마지막 이동(최종 경로 칸)·사격으로 정해진 요원의 전술 기준 방향에 상대적이다. 초기 아군 기준은 동쪽. 엄폐 자세의 시각적 몸 회전 및 카메라 회전과는 독립이다. 선택 버튼에 절대 방위도 표시한다.
- 각 방향의 감시각은 90도(경계선 포함). 사거리·사선·배터리 조건을 모두 만족하는 이동 적에게 자동 1회 사격한다. 선택 중 영역 미리보기, 확정 후 발밑 부채꼴과 분대 상태를 표시한다.

## Ink Tactics / Daylight 그래픽 UI 개편 (2026-09-25)
- 최종 시각 레이어: src/graphic-ui.css. 밝은 종이색(#faf7ed), 청회색 잉크(#263e50), 전술 청회색(#416783), 황동 강조(#ad7935), 보조 회색(#61707a)을 사용한다. AI 전술 강조는 회보라색(#77628c).
- 선택한 아군은 잉크색 한 면과 밝은 글자로 구분한다. 중복 테두리/그림자 강조를 피하고 키보드 포커스만 별도 외곽선을 사용한다.
- 요원 초상·HP·AP·상태·배터리를 한 카드에 배치. 배터리는 눈금과 숫자 및 접근성 이름을 함께 제공한다. 1280×720에서 4명 모두 보이도록 카드 높이 90px 기준으로 조정했다.
- 명령창은 큰 초상 헤더, 2열 행동 타일, 비용/상태 안내, 황동 상단선으로 구성한다. 장비와 경계 하위 선택을 유지하며 작은 화면에서는 내부 스크롤을 허용한다.
- 공격 확인창은 지표 배경과 숫자 위계를 강화하고 전장 높이를 넘지 않도록 최대 높이를 제한한다.
- 하단 작전 영역은 목표/기록/정보를 세로 구분선으로 나누고 턴 종료는 명확한 잉크색 행동 버튼으로 표시한다.
- 진영 카드·브리핑·편성 상세도 같은 재질과 강조 규칙을 공유한다. 승인된 기존 일러스트를 사용하며 이모지·장식용 화살표는 추가하지 않았다.
- 디자인 시스템 페이지 07 GRAPHIC SYSTEM에 새 팔레트와 원칙을 추가했다. Chrome·Edge에서 1280×720 전투/명령 및 1600×1000 편성/방어 화면을 확인했다. 전투 규칙 변경은 없다.
