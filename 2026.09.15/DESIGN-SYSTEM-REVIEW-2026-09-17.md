# 홈페이지 디자인 시스템 점검 결과

2026-09-17. 범위: index.html / en.html, 공통 CSS, 캔버스 조작 UI, 목차·파트너·엘리베이터·플로팅, 문의·기사·이미지 모달 및 디자인 시스템 예시.

## 수정 사항

- 521~760px에서 목차 터치 영역이 약 30px였던 문제를 수정해 44px 이상 확보.
- 홈 아이콘 클릭 영역을 PC 40px, 모바일 44px로 확보.
- 목차 글자 크기를 typography.css와 공통 토큰으로 이동. 데스크톱의 촘촘한 텍스트 링크 유지.
- 소개·회사 영역의 불규칙한 주요 여백을 공통 간격으로 정리.
- 문의 입력창 경계 대비를 color-border-input으로 복원하고 wf-field 구조 적용.
- 문의 전송 중 aria-busy와 엘리베이터 목적지 title 추가.
- 활동 이미지 포커스 스타일을 공통 토큰으로 통일.
- 앵커 이동 시 scroll-padding과 scroll-margin의 중복 24px 여백 제거.
- 공통 컨트롤 패딩과 본문 줄높이 토큰 정리.

## 검증

- 로컬 Edge 헤드리스: 한국어·영어 × 1280 / 760 / 412 / 390 / 320px, 높이 914px.
- 전 조합에서 가로 넘침 및 JavaScript 실행 오류 없음. 모바일 표시 조작 요소 높이 44px 기준 통과.
- 문의 모달 Escape 닫기와 실행 버튼으로 초점 복귀, 언어 전환 후 입력 보존 확인.
- 캔버스 재생 → 제품 미리보기 모달 → 닫기 → 재생 버튼 초점 복귀 → 초기화 확인.
- 기사 모달 열기·Escape·초점 복귀 확인.
- 목차 이동 후 제목 상단 24px, 엘리베이터 첫 층 scrollY=0, 마지막 층 아래 버튼 비활성 확인.
- 파트너 로고 로딩, 모바일 문의 모달 가로 넘침 없음, 디자인 시스템 예시 모바일 가로 넘침 없음.
- 홈페이지·모달·파트너 스크린샷 확인. 원본 로그와 이미지: tmp/design-audit/.
- 한영 페이지 빌드, JavaScript 구문 검사, git diff --check 통과.

## 범위와 한계

- 실제 문의를 전송하지 않았으며 전송 중 aria-busy는 소스에서 확인했다.
- 별도 워크숍과 타사 라이브러리 내부 UI는 이번 홈페이지 공통 스타일 수정 대상이 아니다.
- 실제 모바일 기기와 모든 브라우저 조합, 모든 캔버스 애니메이션 프레임을 전수 검증한 것은 아니다.
- CSS의 --swatch / --sample-space는 예시 페이지 JavaScript에서 설정하는 동적 변수이며, #000 마스크는 장식의 불투명도용이다.
