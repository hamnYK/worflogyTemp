개요는 AI 에이전트 구조를 억지로 덧붙이지 않고 별도의 순차 시연으로 재생합니다.

## 화살표 의미
사용자의 설명에 따라 화살표는 처리 순서가 아닌 오브젝트 간 상호작용과 영향 방향입니다. 시연의 장면 순서는 설명을 위한 순서이며 실제 시스템 실행 순서를 의미하지 않습니다. 원본 방향과 되먹임 관계를 유지하고 연관 오브젝트 사이의 움직임으로 표현합니다.

## 2.5D 쿼터뷰
도면의 논리 좌표를 등각 투영해 쿼터뷰 공간으로 표현합니다. 로직과 기술 인프라는 구분된 지면에 배치하고, 오브젝트에는 높이와 그림자를 적용합니다. 관계 데이터 자체의 방향은 변경하지 않습니다.

## 첫 도면 상세 수정
사용자 설명을 기준으로 온톨로지를 '시맨틱 코스모스'로 표현.
Top-Down: 전체론적 해석 → 위에서 아래로 구조화 → 고정 노드 네트워크 강화 → 시맨틱스.
Bottom-Up: 전체론적 해석 → 체계역학 재구성 + 위크시그널 → 노드·관계 성장 → 시맨틱스.
공통: 만들어진 시맨틱스가 모여 온톨로지를 구성.
기존 워플로지→온톨로지 직결을 시맨틱스→온톨로지로 교정하고 전체론적 해석→체계역학 영향 관계 추가.
최신 정정 그림에 따라 전체론적 해석→Bottom-Up 및 위크시그널→Bottom-Up 직결은 제거. 두 입력은 체계역학 디자인을 거쳐 Bottom-Up으로 이어집니다.
2017년 독창적 IP 확보는 회사 제공 설명으로 반영. 특허번호·등록증 등은 별도로 확인하지 않음.
W3C와 P사에 관한 설명은 이 시연에서 외부 검증 사실로 추가 공표하지 않음.
그래픽 오브젝트는 관측 장치 / 되먹임 장치 / 신호 수신 장치 / 계층 구조 / 성장 구조 / 의미 관계 단위 / 코스모스로 구체화.
js/overview-story.js에서 첫 도면 전용 시연을 관리하며 나머지 솔루션 시연과 분리.

## 강조점: 고안 주체와 성장 루프
온톨로지를 구성하는 두 가지 방법을 소개하고, 그중 Bottom-Up은 워플로지가 고안한 방식임을 강조합니다.
Top-Down 시연은 노드 6개를 유지하며 연결 강도가 증가합니다.
Bottom-Up 시연은 신호 반영과 관계 생성을 세 번 반복하여 노드가 3→5→7→9개로 증가합니다. 횟수와 개수는 개념 설명을 위한 예시입니다.
첫 도면 엔딩은 두 방식만 표시하고 'Bottom-Up Network Growth Loop — Invented by WORFLOGY'를 강조합니다.
브라우저 검증: 강화/성장 구분, 두 경로의 시맨틱스 축적, 코스모스 완성, 7개 후속 시연, 전환 취소, 모바일 가로 넘침 없음.
최신 정정 그림의 확정 관계: 전체론적 해석→링크드데이터, 전체론적 해석→체계역학, 위크시그널 이론→체계역학, 체계역학→워플로지 Bottom-Up, 링크드데이터→시맨틱스, 워플로지→시맨틱스, 시맨틱스→온톨로지. 정적 화살표·시연 입자·영어 자막 모두 동일한 관계를 따릅니다.
## 최신 시연 방식: 두 개의 독립된 완성 과정
이 절은 앞서 기재된 '두 방식의 시맨틱스를 합쳐 하나의 코스모스 구성' 시연 설명을 대체합니다.
1. 전통적인 Top-Down: 전체론적 해석 → Top-Down 구조화 → 기존 네트워크 강화 루프 → 시맨틱스 → Top-Down만의 시맨틱 코스모스 완성.
2. 전환: 표시 중인 시맨틱스와 코스모스를 비우고 두 번째 시연 시작. 첫 방식의 완성 여부는 내부 상태에만 보존.
3. 워플로지 Bottom-Up: 전체론적 해석 + 위크시그널 → 체계역학 → 네트워크 성장 루프 → 시맨틱스 → Bottom-Up만의 시맨틱 코스모스 완성.
각 완성 장면을 별도로 유지하며 Top-Down은 네트워크 강화를, Bottom-Up은 네트워크 성장을 지향하는 시맨틱 기술임을 영어 캔버스 자막으로 강조합니다.
