## TD4. JavaScript 아키텍처 — **위험**

|---|---|

| `setTimeout / setInterval` | **7개** |
| 전역 함수 선언 | **165개** |

**문제**:
- **220개 `onclick=`**: HTML에 이벤트가 직접 박혀 있어 이벤트 위임 불가, 테스트 불가, 함수명 변경 시 HTML까지 수정 필요.

**해결 방향**: `addEventListener` 위임 패턴 도입. `var` → `let`/`const` 전환.

**문제**:
